A row × column grid for 2D frameworks — e.g. which measurement method fits which use case. Tinted row/column headers in one accent color, plain cells.

```jsx
<Matrix
  chapter={5}
  rowLabels={['MaxDiff', 'Conjoint', 'TURF']}
  colLabels={['Ranks items', 'Gives $ value', 'Picks a bundle']}
  cells={[['✓','–','–'],['–','✓','–'],['–','–','✓']]}
/>
```
