Standard top-of-page badge for every content page except the Cover Page: a week/session pill plus an uppercase mono page-type label. Use the same `chapter` (the document's primary/brand color) on every page in a packet, so the identity reads as one document — section-level content inside the page can still use its own topic chapter colors.

```jsx
<PageBadge week="Week 3" label="Appendix" chapter={1} />
```
