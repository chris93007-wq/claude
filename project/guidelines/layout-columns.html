US Letter, 0.5in margin (the padding shown inside each box) — 8.5 × 11in portrait, 11 × 8.5in landscape.
Portrait (default): 1 column for prose/callouts; 2 columns once content is short, scannable blocks (definitions, tables, flashcards) — see Notes Page.
Landscape: reflow to 3-4 columns to use the extra width — best for flashcard grids, comparison tables, or dense reference pages (Appendix).
Mixed rows: within one page, rows can alternate — a full-bleed row (heading, callout, wide table) followed by a row split into 2-4 columns — same Material 12-col logic as above, just applied row by row instead of to the whole page.
Inside cards & sections: the same column logic applies one level down — a card's own body, or a Section's content area, can split into 2-4 columns rather than the whole page row (e.g. ConceptCard pairs in Notes Page, or a Section holding a 3-up flashcard row).
